## 予備の題材

- Nova 2 Sonic の双方向ストリーミングは、イベントを送る順序を間違えるとエラーになる
- DynamoDB の条件付き書き込みで、チケットの二重消費を防いだ
- Kiro の Automations から npm レジストリに届かなかったので、オフラインのキャッシュを用意した
- Next.js を OpenNext と CDK で AWS に載せた
- Cognito の Pre sign-up トリガーで招待制にする
- GitHub Actions から OIDC で CDK をデプロイする
- Strands Agents の Graph を調べて、LangGraph と比べた
- Amazon Polly と Nova 2 Sonic の使い分け
